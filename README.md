# KeybindsPlus

KeybindsPlus is a plugin that allows you to bind *almost* any key on your keyboard and mouse to XIV actions, custom macros/commands, and supported Dalamud plugins. Bind any key, including those not normally supported by the game (F13-F24) to *almost* anything as if it were an actual registered keybind!

Supported Keybinds:
- Custom Macros and Commands
- Supported Plugins
- Targeting*
- Shortcuts
- Chat*
- Hotbars
    
    > \* - Some features may be grayed out due to complexities or unavailability. Not all base game keybinds are in KeybindsPlus but may appear as updates progress.
